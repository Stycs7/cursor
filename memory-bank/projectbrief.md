# Project brief

Design and ship a WordPress website for Shearwater Victoria Falls: a Victoria Falls adventure, lodge, and dining operator (Zimbabwe), so guests can browse experiences, stay at Explorers Village, and enquire.

## Goals

- A distinctive custom theme, not a generic tourism template
- Pages: Home, Experiences, Stay, Dine, About, Contact
- Installable on WordPress 6.4+ and reviewable as static HTML
- Accurate public facts (1984 origin, 400m lodge, activity families, contact details)

## Out of scope for this pass

- Live booking / payment gateway
- Official Shearwater photography library
- Multi-language
